THE WORK, STEP BY STEPUpdated October 2026

Built over time.
Still moving forward.

What we built, what we are working on now, what mainnet needs and what comes after it.

  1. OCTOBER 2025 – JANUARY 2026

    Where it started: a post-quantum messenger

    DNA Messenger with its DHT and multi-chain wallet, and the first code of our own chain.

    BUILT
  2. FEBRUARY – APRIL 2026

    Nodus: our own network

    A pure C DHT replaced OpenDHT; media storage, encrypted relay and the chain node came together in one server family.

    BUILT
  3. APRIL – SEPTEMBER 2026

    The chain takes shape

    Staking, delegation and governance, Ledger V2, the CometBFT consensus port and the Scan explorer.

    BUILT
  4. 30 SEPTEMBER 2026

    The testnet is live

    A public testnet; its coin is NODUS. No more resets: a rule change takes effect at a block height the witnesses vote for — a hard fork.

    BUILT
  5. 30 SEPTEMBER 2026 · HF-1

    HF-1: gas price

    A transaction pays for the work it declares, with a minimum fee. In force from block 0.

    BUILT
  6. 1 OCTOBER 2026 · HF-2

    HF-2: governance by voting power

    A chain-parameter change needs more than two thirds of the voting power. Live since block 1,500.

    BUILT
  7. 2 OCTOBER 2026 · HF-3

    HF-3: block size set by the consensus limits

    The old fixed byte and unit limits are gone. Live since block 2,926.

    BUILT
  8. 2 OCTOBER 2026 · HF-4

    HF-4: on-chain names

    Register a name for a Nodus address and send to the name. Live since block 3,151.

    BUILT
  9. 7 OCTOBER 2026 · HF-5

    HF-5: smart contracts with Nodus EVM

    Our own EVM engine runs Ethereum smart contracts, with addresses from post-quantum keys. Live since block 79,757.

    BUILT
  10. 13 OCTOBER 2026 · HF-6

    HF-6: node owners, a lower witness bond and paid storage nodes

    A witness needs a bond of at least 2 million NODUS, and anyone can run a storage node that earns from the Storage pool. Live since block 176,100.

    BUILT
  11. 20 OCTOBER 2026 · HF-7

    HF-7: a full state root, replay protection and transaction expiry

    Every table a block reads is covered by the state root; a transaction expires and cannot be applied twice. Live since block 282,684.

    BUILT
  12. 21 OCTOBER 2026 · HF-8

    HF-8: delegating needs a chain name

    A new delegation needs the delegating address to own a chain name. Live since block 300,722.

    BUILT
  13. 22 OCTOBER 2026 · HF EVM-ML-DSA

    HF EVM-ML-DSA: post-quantum signatures in smart contracts

    A smart contract can verify an ML-DSA-87 signature. Live since block 306,911.

    BUILT
  14. OCTOBER 2026

    Web wallet and Nodus Connect

    Send, receive and delegate NODUS in the browser, with chain names, shared vaults, the test token tUSDT and a testnet faucet. Nodus Connect — wallet and messages in one app — is a preview.

    BUILT
  15. NOW · HF-9

    HF-9: one keyed tree for the chain’s state

    Lets a light client or a home storage node prove a single record without downloading whole lists. In design; it takes effect only after a witness vote.

    NOW
  16. NOW

    DHT v2

    The next version of the network’s distributed storage.

    NOW
  17. NOW

    A home storage node for Windows

    Run a storage node at home and earn from the Storage pool. It comes after HF-9.

    NOW
  18. NOW

    First airdrop: CPUNK community

    10,000,000 NODUS (1% of the total supply) for the CPUNK community. Registering and claiming in Nodus Connect come next; the start will be announced.

    NOW
  19. MAINNET

    Mainnet: a new genesis

    Mainnet starts from a new genesis, with every hard fork active from block 0. The testnet keeps running beside it. There is no date: mainnet launches when the list below is done.

    MAINNET
  20. MAINNET

    What mainnet needs

    HF-9; one rewarded storage node per IP address; penalties for witnesses that sign twice (slashing); vesting for the founder and Foundation shares; DHT v2; Nodus Connect on desktop and the command line; the home storage node; a DEX; and every open finding closed down to low severity.

    MAINNET
  21. AFTER MAINNET

    An automated market maker (AMM)

    Swap against a liquidity pool, next to the DEX.

    LATER
  22. AFTER MAINNET

    Bandwidth for VoIP and beyond

    Extend the relay foundation into a bandwidth service for real-time calls and other network traffic.

    LATER
  23. AFTER MAINNET

    One identity on several devices

    Use the same identity on a phone and a computer.

    LATER
  24. AFTER MAINNET

    Storage capacity market

    Buy space for personal files and application data through a storage marketplace built around the Nodus network.

    LATER
  25. AFTER MAINNET

    Compute market

    Bring STARK proof-generation jobs and AI-training workloads to a market for compute capacity.

    LATER

Dates mark development milestones. Mainnet and everything after it have no date. Scan lists every hard fork with its vote.
