THE WORK, STEP BY STEPUpdated September 2026

Built over time.
Still moving forward.

From the first messenger to a resource network. Follow the dated development milestones, the work underway, and the next services taking shape.

  1. OCTOBER 2025

    The first messenger foundation

    DNA Messenger and its C library API were introduced, with key generation, encryption, and recovery as the starting point.

    IMPLEMENTED
  2. NOVEMBER 2025

    Distributed communication and mobile foundations

    DHT transport, signed profiles, group messaging, Android builds, and the Flutter/FFI foundation were added during November.

    IMPLEMENTED
  3. DECEMBER 2025

    The wallet grows across networks

    Ethereum, Solana, and TRON support joined the wallet, extending the existing Cellframe integration.

    IMPLEMENTED
  4. JANUARY 2026

    Native chain development begins

    The DNAC project was introduced for native transactions, wallet operations, and chain development.

    IMPLEMENTED
  5. FEBRUARY–MARCH 2026

    Nodus becomes the native network

    The pure C Nodus DHT replaced OpenDHT. Application integration and embedded witness infrastructure brought storage and the chain into the same server family.

    IMPLEMENTED
  6. MARCH–APRIL 2026

    Media storage and encrypted relay

    Persistent, resumable media uploads and endpoint-to-endpoint encrypted circuits expanded what applications could store and transport.

    IMPLEMENTED
  7. APRIL 2026

    Staking, delegation, and chain governance

    Validator and delegation flows, wallet screens, committee-voted parameters, epoch settlement, and supply checks were implemented.

    IMPLEMENTED
  8. JULY 2026

    Call signaling, C proofs, and Scan

    Call signaling and per-call key agreement, a C STARK prover/verifier, and the block explorer with its JSON API were added. Batched STARK work followed. Real-time call media remained a separate next step.

    IMPLEMENTED
  9. AUGUST 2026

    Ledger V2 takes shape

    Modular domains, atomic block execution, manifests and claims, and independent V2 genesis were implemented. The new ledger can start as its own development chain.

    IMPLEMENTED
  10. SEPTEMBER 2026

    Ledger V2 integration scenarios

    The V2 Genesis Protocol exercised multi-node startup, joining, recovery, restart, and epoch-boundary behavior. Broader consensus work continues.

    IMPLEMENTED
  11. SEPTEMBER 2026 / NOW

    Consensus: the CometBFT reference port

    The CometBFT reference port now includes the types layer and consensus core, with vote sets, persistence, replay and scenario tests. Integration with the network host and ledger is the next step.

    IN PROGRESS
  12. NEXT

    Storage capacity market

    Buy space for personal files and application data through a storage marketplace built around the Nodus network.

    PLANNED
  13. NEXT

    Bandwidth for VoIP and beyond

    Extend the relay foundation into a bandwidth service for real-time calls and other network traffic.

    PLANNED
  14. NEXT

    Compute market

    Bring STARK proof-generation jobs and AI-training workloads to a market for compute capacity.

    PLANNED

Dates record development milestones in the project history. Completing a component does not mean every related service has launched. Planned services have no announced launch date.
