Explorer API

All endpoints use GET. Block and address lists accept a limit from 1 to 100. Pagination uses a strict before cursor: block height for blocks, ledger sequence for address history.

/api/stats
/api/blocks?limit=25
/api/block/<height-or-hash>
/api/tx/<hash>
/api/address/<fingerprint>?limit=25
/api/search?q=<term>

Money fields are decimal strings in base units with eight decimals for DNAC. Preserve integer precision when formatting them. Unknown stats can be null; an unavailable index can return HTTP 503.
