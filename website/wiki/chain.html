Chain & NODUS

The ledger behind the network’s next chapter.

REVIEWED SEPTEMBER 2026EN / TR

A development network

The native chain currently uses DNAC on devnet. It is a development environment and can be reset. The Nodus name and NODUS ticker are planned with testnet; no public testnet date is announced here.

What is implemented

Development includes transparent UTXO accounting, native assets, staking, delegation and chain parameters. Ledger V2 adds modular domains and independent genesis. The CometBFT reference port includes a types layer and consensus core; host and ledger integration remain ongoing work.

These implementation milestones do not announce a deployed public service. Shielded payments remain development work.

Read the ledger

Nodus Scan displays indexed blocks, transactions and address history. The current transparent ledger exposes transaction amounts and address information. Scan does not sign transactions or independently re-verify consensus certificates.
