Chain & NODUS

The ledger behind the network’s next chapter.

REVIEWED SEPTEMBER 2026EN / TR

A test network

The native chain has run as a public testnet since 30 September 2026, and its coin is NODUS. There are no more resets: changes to the chain’s rules take effect as hard forks at an agreed block height. Some code and tools still use the DNAC name during the transition.

Hard forks on the testnet

Seven hard forks are active. The first was set in the genesis document; the other six were switched on by witness votes.

  • HF-1, from block 0: a transaction pays a fee of its units times the gas price, with a minimum.
  • HF-2, from block 1,500: governance approvals are weighed by voting power and need more than two thirds of it.
  • HF-3, from block 2,926: a block is bounded only by the consensus limits.
  • HF-4, from block 3,151: rule-set generation 2, with on-chain names.
  • HF-5, from block 79,757: rule-set generation 3, with smart contracts on Nodus EVM. Voted in at block 62,425.
  • HF-6, from block 176,100: rule-set generation 4. A witness or storage node is registered by the wallet that owns it, with the node’s consent; the witness bond is at least 2,000,000 NODUS; the voting power counted for one witness is capped at 30%; storage nodes are paid for keeping the block archive. Voted in at block 175,307.
  • HF-7, from block 282,684: rule-set generation 5, the roots generation. Every table a block’s execution reads is covered by the state root, so a new node will be able to start from a verified snapshot instead of replaying every block (the snapshot download itself is not built yet); a transaction must carry an expiry no later than 720 blocks ahead (about 100 minutes); a transaction already applied cannot be applied again while it is unexpired; transactions signed before block 282,684 are no longer valid. Voted in at block 281,957.

What is implemented

Development includes transparent UTXO accounting, native assets, staking, delegation and chain parameters. Ledger V2 adds modular domains and independent genesis. The CometBFT reference port is merged and runs the testnet, together with its peer-to-peer layer on port 4004. Scan reads this chain.

These implementation milestones do not announce a deployed public service. Shielded payments remain development work.

Earn NODUS

On the testnet today there are three ways to earn NODUS. Two are paid from the 200,000,000 NODUS reward reserve: run a witness, or delegate NODUS to one. The third is paid from the Storage pool: run a storage node.

  • Run a witness: bond at least 2,000,000 NODUS and run a node that signs blocks. The wallet that owns the witness puts up the bond and receives the rewards; the node only gives its consent. Up to 32 witnesses are active, chosen by total stake. Each witness sets its commission, up to 50%. Become a witness from Nodus Connect (More → Nodus) or with the nodus-cli tool; see Run a node. After unstaking, the bond is locked for 84 epochs.
  • Delegate: at least 100 NODUS, from Earn in the web wallet or Nodus Connect. Undelegated NODUS is locked for 12 epochs.
  • Run a storage node: bond 1,000,000 NODUS and keep parts of the block archive; see Run a node.

An epoch is 720 blocks. At the end of each epoch, 1/65,536 of the reserve is shared by stake among the witnesses that met the participation rule, and their delegators get their part minus the witness’s commission. Rewards are paid every 24 epochs, on a payday every 17,280 blocks. No stake is cut today.

Planned, not live

The changes below have been decided but are not running on the chain. They arrive only with a hard fork that witnesses vote in, and the numbers can still change. HF-5 (Nodus EVM, live since block 79,757) and HF-6 (node owners, the lower witness bond, the power cap and paid storage nodes, live since block 176,100) are no longer planned — see the hard fork list above. The storage reward came with HF-6; the HF-7 number now belongs to the roots generation, live since block 282,684.

  • Compute and bandwidth roles: their own stake — compute 1,000,000 and bandwidth 500,000 NODUS — and their own reward from the Compute and Bandwidth pools.
  • HF-8: a new delegation, or adding to one, needs the delegating address to own a chain name. Existing delegations and their rewards are not affected, and a witness’s owner delegating to that witness does not need a name.
