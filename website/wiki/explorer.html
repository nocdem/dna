Using Nodus Scan

Follow a block. Find a transaction. Understand an address.

REVIEWED SEPTEMBER 2026EN / TR

Find a record

Search by decimal block height, a transaction position written as height:index, a block id, a transaction wire id or intent id, or an address fingerprint. Ids and address fingerprints use 128 hexadecimal characters. If a term matches more than one record type, choose the result you need.

Read the detail pages

Block pages show the header and the block’s transactions, page by page. Transaction pages show the position, status (applied or refused), wire and intent ids, fee, inputs and outputs, and any recorded staking or configuration change. Address pages show balances per token as reported by the network — total, spendable now and coin count — and the address’s indexed transaction history.

Understand the data source

Scan is a read-only indexer that trusts responses from its configured witness cluster. Indexed data can lag; balances come live from the network and may reflect a later block than the indexed history. An unavailable API is shown as unavailable, never as an empty chain or zero balance.

Current supply is the supply reported by the testnet. It is not a claim about market circulation.
