Using Nodus Scan

Follow a block. Find a transaction. Understand an address.

REVIEWED SEPTEMBER 2026EN / TR

Find a record

Search by decimal block height, a full block or transaction hash, or an address fingerprint. Hashes and address fingerprints use 128 hexadecimal characters. If a term matches more than one record type, choose the result you need.

Read the detail pages

Block pages show the header and transaction list. Transaction pages show inputs, outputs, fees and raw bytes. Address pages show indexed native balance and history, with unspent outputs requested separately from witnesses.

Understand the data source

Scan is a read-only indexer that trusts responses from its configured witness cluster. Indexed data can lag; separately requested live outputs may reflect a later block. An unavailable API is shown as unavailable, never as an empty chain or zero balance.

Current supply is the supply reported by the development chain. It is not a claim about market circulation.
