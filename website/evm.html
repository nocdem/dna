Nodus EVM

Smart contracts on Nodus Chain. Our own EVM engine runs Ethereum’s Prague rules, and contracts are written in Solidity.

Developer guide↗Open Wallet↗
CONTRACTS UNDER POST-QUANTUM KEYS

A closer look.

  1. 01

    Post-quantum signatures. Every contract transaction is signed with your Nodus identity’s ML-DSA-87 key, not with secp256k1.

  2. 02

    32-byte addresses. An address is 64 hexadecimal characters, in the ABI as well. A 20-byte Ethereum address padded with zeros is a different account.

  3. 03

    Fees in NODUS. Every contract transaction pays its fee in NODUS from your coins, and a call that fails is still included and still pays.

Live on the testnet since block 79,757 (7 October 2026). Witnesses switched it on by vote: hard fork HF-5, voted at block 62,425. This is a testnet, and the tools around it are early: the wallet panel is a preview.

The tools you use.

MetaMask, ethers, viem and eth_* JSON-RPC expect 20-byte addresses, so they do not work with Nodus EVM. Use one of these instead:

  • The smart-contracts panel in the web wallet and in Nodus Connect (preview). It shows your EVM address and balance, deploys a contract from its bytecode and ABI, and reads and writes contracts. Every transaction is reviewed before signing.
  • nodus-cli, the command-line tool: deploy, call and send, with receipts and events. It tries a call before sending it and stops if it would fail.
  • A JavaScript SDK for Node.js scripts. It is kept in the source repository and is not published on npm; it reuses the web wallet’s own code.

How to start.

A standard Solidity compiler cuts addresses to 20 bytes, so contracts need the Nodus solc: Solidity 0.8.30 with 32-byte addresses.

  • Read the smart-contracts guide in the Wiki: installing the compiler, deploying, calling, receipts and events.
  • Download the Nodus solc for Linux x86-64 and check it against its sha256: a09d6486c944a795009f08dbc8210ce2eee2785248f9f5f7edc2aaa9c6934649
  • Begin with the example token in the repository, NodusToken.sol: a minimal ERC-20-style token whose deployer receives 1,000,000 tokens.

Nodus EVM follows Ethereum’s Prague rules, without blob and set-code transactions. Inside the EVM, 1 NODUS = 1018 wei.
