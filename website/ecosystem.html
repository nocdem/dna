A LITTLE MORE CONTEXT

Glad you asked.

What is Nodus?+

Nodus is a post-quantum infrastructure ecosystem. Storage is its existing foundation; the direction is a resource network with storage capacity, bandwidth, and compute markets. Connect, Wallet, Identity, Chain, and Scan bring applications and settlement to that network.

Is the chain live on mainnet?+

No. The chain is currently on devnet under the DNAC name. The Nodus name and NODUS ticker are planned for the testnet transition. A public testnet date has not been announced here.

How does this relate to DNA?+

Nodus is the new identity for the DNA ecosystem, with a brand separate from CPUNK. Current code, downloads, and service addresses still use some DNA and CPUNK names during the transition.

Where can I explore the code?+

The native libraries and network are Apache 2.0; the Flutter app is source-available under a proprietary license. The developer overview links to the code and component licenses. Developer overview ↗

What does private mean here?+

Private message content is end-to-end encrypted. Public social posts are public, and network nodes can observe connection metadata such as IP addresses and timing. See the developer guide for the security scope.
