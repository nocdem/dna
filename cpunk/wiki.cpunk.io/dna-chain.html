DNA Chain FAQ

DNA Chain is the DNA ecosystem's own blockchain, built from the ground up with new-generation encryption. It is currently in early development — here is what that means for you.

Status: development network

DNA Chain currently runs as a developer network (a "devnet") used to build and test the system. It is not yet open for public use, and the network may be reset during development. A public test network will be announced on cpunk.io when it is ready.

Common questions

What is DNA Chain?

DNA Chain is a blockchain — a shared ledger kept in agreement by many independent computers instead of one company. It is being built as the payments and value layer of the DNA ecosystem, with its native coin, DNAC.

What makes it different from other blockchains?

It is built with post-quantum cryptography throughout — encryption designed to stay secure even against future quantum computers. Most existing blockchains rely on older cryptography that quantum computers are expected to break one day.

Can I use it today?

Not yet. The chain currently runs as a development network for building and testing. Coins on the development network have no real-world value, and the network may be reset as development continues.

When can I try it?

A public test network is planned as the next step. Dates and details will be announced on cpunk.io — no schedule is promised until it is genuinely ready.

How does it relate to the CPUNK token?

The CPUNK token exists today and is separate from DNA Chain, which is still in development. How the two will connect is a decision the community will be part of — announcements will be made on cpunk.io.

Can I watch the chain live?

Yes — the block explorer at scan.cpunk.io shows the development network in real time: blocks, transactions, and addresses. It's a window into the chain as it is being built.

Does DNA Connect already use DNA Chain?

Yes. The wallet in DNA Connect connects to the development network today — DNAC balances and transfers run on it. That is how the chain gets tested: with the real app, before anything of real value is on the line.

Is the code open source?

Yes. The DNA ecosystem — including DNA Connect and the DNA Chain software — is developed in the open. You can read the code at gitlab.cpunk.io/cpunk/dna.

What is being built next?

The chain is being rebuilt on a new ledger design called Ledger V2. In plain terms it does three things: it lets new capabilities be added later without disrupting the network, it makes every block commit to much more of its own history, and it adds built-in private transfers. It is in development now.

Will the development network be reset again?

Yes. Ledger V2 starts as a fresh chain rather than an upgrade of the current one, so the development network will be restarted from scratch when it lands. Coins on the development network have no real-world value, so nothing of value is lost.
