# Ixios native transaction oracle

`oracle.go` is a synthetic harness against official ixiosSpark v1.1.1 commit
`ccd1345eed8873a6d0174b3e9a076da67ceb7750`; it emits `vectors.json`, including
both native 48-byte and zero-prefix compact 32-byte destination encodings. It
uses deterministic public test seed `000102...1f`; no real wallet key or funds.
Native `MarshalBinary`, `UnmarshalBinary`, `Sender` and negative signature,
nonce, gas-price, recipient and chain-ID controls are exercised. The `2e9`
gas price in these vectors is **codec only**, not an admissible mainnet fee.

From a checkout of the exact tag and a Go installation, with dependencies
already acquired, run (paths adapted):

```sh
cd /tmp/ixios-spark-v111
GOCACHE=/tmp/wallet-gocache GOPATH=/tmp/wallet-gopath GOPROXY=off \
 /tmp/wallet-golang/go/bin/go run /path/to/web-wallet/test/ixios-reference/oracle.go
GOCACHE=/tmp/wallet-gocache GOPATH=/tmp/wallet-gopath GOPROXY=off \
 /tmp/wallet-golang/go/bin/go run /path/to/web-wallet/test/ixios-reference/verify.go /path/to/web-wallet/test/ixios-reference/hedged.hex
```

`hedged.hex` is generated by the browser WASM using the same synthetic seed,
with deterministic test randomness of 32 bytes of `07`. Native Ixios decoding
and ML-DSA sender recovery accepts it, yielding hash
`0x0637e4ab833c56a01dca8c6651b416eba178e009ee45db36ab028777ffde6d19`.
This is signature/serialization evidence, not a transaction admission,
full-state execution, public RPC broadcast, or finality claim.

The public-input-only verifier is built from `crypto/ixios-mldsa87-verify.c`
and the repository-pinned `shared/crypto/sign/dsa` sources using
`scripts/build-ixios-verify-wasm.sh` (observed Emscripten 6.0.13); it exports
no seed, key generation, or signing API. Its SHA-256 is
`5b73f42fa0f1e0ad4f9fcd7c72693a674f228c6b5917cedf7f45567aad6dee8a`.
The wallet's existing signing WASM is a separate module. Reproduction tests
accept native-generated signatures and reject tampering of the recipient,
nonce, gas price, amount, and signature.
